# Phase 0 · Requirements register

P0 records the baseline. These requirements are prospective gates. P0 does not assert that any acceptance thresholds below are already met. **Critical** blocks reliance on affected results or a production release. **High** is required for the relevant phase. **Medium** is scheduled work. E1 and E2 follow the [ownership plan](07-two-engineer-development-plan.md).
