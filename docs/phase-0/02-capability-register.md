# Phase 0 · Capability register

Status applies to the stated scope at commit 74f364d. **Implemented and verified** means an executed check confirms the bounded behavior described. **Implemented but not verified** means an active code path exists without adequate executed evidence. **Partially implemented** indicates a missing part of the requested capability. **Planned only**, **Missing**, and **Deprecated or unused** refer respectively to a proposal, no active implementation located, and a retained path outside the ordinary workflow. A passing fixture is not independent industrial validation. See the [executed checks and limits](06-testing-and-security-audit.md).
