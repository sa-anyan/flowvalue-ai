# Equipment page refinement

The costing directory now uses the shared blue equipment accent, a compact summary, readable card typography and explicit estimated/review states. Grouped units, card/list views, search, sorting and filtering are retained. Active filters expose a reset action. Reports and exports remain in a collapsed section instead of preceding the directory.

The right-hand inspector retains model rationale and existing edit controls. Its tabs support arrow keys/Home/End; Escape, focus trapping, focus restoration and unsaved-change confirmation remain in place. Edit labels distinguish unsaved changes from saved data. Recalculation guidance points to Engineering Data, where the existing Run Again action resides. Numeric saved decimal cost strings display as costs rather than being labelled unpriced; this changes formatting only, not calculations.

Read-only browser verification covered individual cards, grouped-unit expansion, list view, search/reset, cost and assumption tabs, keyboard navigation/Escape, desktop/mobile overflow and dark mode. No save, baseline edit, paid AI call or external research was triggered. QA artifacts are under ignored outputs/equipment-polish.
