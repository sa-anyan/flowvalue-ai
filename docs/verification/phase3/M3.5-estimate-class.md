# M3.5 · AACE estimate class proposal

**Date:** 12 November 2026 · **Owner:** Engineer 1 · **Gate:** G3, "estimate class consistent with design maturity" · **Status:** proposal for review. The deliverable checklist is provisional until checked against the purchased AACE 18R-97.

## What it does

Every CAPEX run now returns `estimate_class`. It proposes an AACE class from the **maturity of the design deliverables**, which 18R-97 calls the sole determining characteristic. It never certifies a class. A reviewer confirms it, or overrides it with a rationale.

| Output | Meaning |
|---|---|
| `proposed_class` | 5, 4 or 3 from the deliverable checklist. Classes 2 and 1 need detailed take-offs, which FlowValue does not produce, so they are never proposed |
| `status` | `proposed` → `confirmed` (reviewer agrees) or `reviewer_override` (different class, rationale required); `invalid_input` if the declarations are malformed (CAPEX still runs) |
| `effective_class`, `class_characteristics` | Reviewer's class if given, else the proposal, with Table 1's end usage, methodology and accuracy range |
| `deliverables` | Each deliverable's status and where it came from: user-declared, derived, or "not stated, treated as absent" |
| `gaps_to_next_class` | What would need to mature to reach the next class |
| `wide_end_reasons` | Costing caveats that put actual accuracy at the wide end of the range, or beyond it. They **never** change the class |
| `issues` | E.g. Class 3 maturity with an equipment-factored CAPEX method |

Code: [`backend/capex/estimate_class.py`](../../../backend/capex/estimate_class.py), wired in [`backend/blocks/capex/runner.py`](../../../backend/blocks/capex/runner.py). Tests: [`backend/tests/test_estimate_class.py`](../../../backend/tests/test_estimate_class.py).

## Source

AACE International RP 18R-97, Rev. 7 August 2020, section 3, **Table 1**, p. 3 of 21: checked on 12 November 2026 against AACE's public sample (`web.aacei.org/docs/default-source/toc/toc_18r-97.pdf`). Only Table 1's class characteristics are used, with this citation. The sample marks the RP as copyright, single-user licence, so nothing else is reproduced.

| Class | Maturity (% of complete definition) | End usage | Accuracy, low / high (80% CI, after contingency) |
|---|---|---|---|
| 5 | 0–2% | Concept screening | −20% to −50% / +30% to +100% |
| 4 | 1–15% | Study or feasibility | −15% to −30% / +20% to +50% |
| 3 | 10–40% | Budget authorization or control | −10% to −20% / +10% to +30% |
| 2 | 30–75% | Control or bid/tender | −5% to −15% / +5% to +20% |
| 1 | 65–100% | Check estimate or bid/tender | −3% to −10% / +3% to +15% |

## Deliverable checklist (FlowValue's own; provisional)

18R-97's Table 3 (deliverable maturity by class) is not in the public sample. This checklist is FlowValue's engineering judgement and must be checked against Table 3 once the RP is purchased.

| Deliverable | Class 4 needs | Class 3 needs | Derived automatically when |
|---|---|---|---|
| Plant capacity, products and feed basis | complete | complete | — |
| Plant location | preliminary | complete | — |
| Block or process flow diagram | preliminary | complete | — |
| Heat and material balance | preliminary | complete | Engineering data approved in FlowValue → preliminary |
| Sized major equipment list | preliminary | complete | Equipment register with sizes → preliminary |
| Equipment data sheets | — | preliminary | — |
| Utility balance | — | preliminary | — |
| P&IDs | — | preliminary | — |
| Plot plan | — | preliminary | — |
| Vendor quotes for major equipment | — | preliminary | Any user price or comparable → preliminary |

**Unknown means absent.** A deliverable nobody has declared counts as "none", and the output says so. The user declares deliverables in the editable plan section `estimate_class`:

```json
{"design_maturity": {"capacity_and_products": "complete", "plant_location": "preliminary", "process_flow_diagram": "preliminary"},
 "new_technology": false,
 "review": {"class": 4, "reviewer": "Engineer 2", "rationale": ""}}
```

Editing this section marks CAPEX stale. The saved study keeps the declarations and the review.

## Charlie (local check; no private values recorded)

- **Nothing declared:** Class 5. The derived balance and equipment list alone do not meet Class 4.
- **Capacity complete, location and PFD preliminary:** **Class 4** (study or feasibility, −15/−30% to +20/+50%). This fits a study built from an M&E balance with factored costing. The founder has to confirm those three declarations.
- **Costing caveats on that run:** 2 of 28 items unpriced (93%, below the 95% G3 target), 12 extrapolated, 26 CPI-proxy escalated. The minimum-size floor (PR #14) changes this to 28 of 28 priced, with 14 floored. CEPCI (PR #16) removes the proxy caveat once a 2025/2026 value is added.
