# Phase 5 audit and first fixes — 12 November 2026

**Owner:** Engineer 1 · **Branch:** `e1/p5-audit` (stacked on PR #29) · **Authority:** official roadmap rev 1.1, Phase 5 (M5.1–M5.7, testing, acceptance criteria, exit gate G5)

> **G5:** AI can reliably assist with supported engineering and commercial workflows while preserving reviewer authority, calculation integrity and source traceability.

## Summary

Most of Phase 5's guard rails already existed when this audit started:

- **Specialist AI roles:** workbook engineer, equipment matcher, design handoff, assumption completion, capital, operating and commercial advisors, analyst team, and Monte Carlo advisor.
- **Bounded outputs:** every role answers through a strict JSON schema, and Python does all the arithmetic.
- **A response cache.**
- **Approval fingerprints** for engineering data and revenue.

This audit built the **fixed G5 evaluation suite** (M5.5): [`benchmark.json`](benchmark.json) plus [`g5_review_reproduce.py`](g5_review_reproduce.py). It maps every roadmap scenario and acceptance criterion to specific tests. It also found and fixed three problems, one of which withdraws a G3 result.

**Fixed:**

1. **Project-specific prompt rules (rev 1.1).** The equipment-matching prompt contained rules written from Team 8's units: "P-001 may mean pH adjustment, NOT a pump", fermenter and clarifier range rules, and a biofilm-reactor rule. They were added on 6 Nov in `b1ad0d3`, before Team 8 was named held out. The workbook-review prompt had a matching pH-adjustment line.
   - All of these are now general principles: a tag prefix does not establish function; correlation ranges are strict.
   - Both prompt versions are bumped.
   - A test now fails if any equipment tag appears in the 17 AI modules.
   - **Consequence:** the Team 8 run does not meet G3's R3, the held-out criterion. The G3 pack and Team 8 record are corrected on this branch.
2. **Model not pinned in the response cache (rev 1.1).** Several AI calls left the model ID out of the cached context. After a model change, a cached answer from the old model could be reused. The local and cloud stores now include the model ID in every cache key.
   - **Side effect:** existing cached AI responses no longer match, so the next AI run of a saved study calls the model again.
3. **No test for instruction injection in an uploaded file.** New tests cover it:
   - a workbook cell saying "IGNORE ALL PREVIOUS INSTRUCTIONS…" is stored verbatim as data;
   - that text reaches the AI only inside the data context, never in its instructions;
   - a compromised answer choosing an unlisted model is rejected.
