## M1.4 — distinct calculation states

| State | How it is represented |
|---|---|
| Missing input | `MissingInputError` (`kind = "missing_input"`) from `engineering_sizing.common` |
| Invalid input | `InvalidInputError` (`kind = "invalid_input"`): Boolean, non-numeric, non-finite, out of range, unknown parameter or unit |
| Unsupported method | `UnsupportedMethodError` (`kind = "unsupported_method"`) from the registry |
| Extrapolated result | Costing requires an explicit exponent and justification outside a correlation's range; graph readings are marked `unverified_graph_reading` |
| Completed | Result with `engineering_method` version metadata; cost lines `calculated` or `provisional` |

All three error classes subclass `ValueError`, so existing callers are unaffected. `test_sizing_error_states.py` covers each state. Passing these states through to the equipment view is part of Engineer 2's METHOD-APP01.
