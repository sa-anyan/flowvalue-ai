# M1.6 · Bridge equations as verified calculation methods

**Date:** 11 November 2026 · **Owner:** Engineer 1 · **Decision: PASS** for the six bridge methods below.

The unit-conversion bridges contain engineering equations that feed costing directly. The Phase 1 production scope list classed them as adapters, so they had no method-level reference cases. This milestone treats each as a calculation method: it records a governing equation, independent reference, applicability and limits, and adds reference tests.

| Method | Equation | Reference test values |
|---|---|---|
| LMTD, countercurrent | (dT1 − dT2)/ln(dT1/dT2), dT1 = Th,in − Tc,out | 150→100 °C hot, 20→60 °C cold: 84.90187015703761725 K |
| LMTD, parallel | dT1 = Th,in − Tc,in | Same streams: 76.35822210854355034 K; area 1.0476933300814632 m² at 40 kW, U = 500 W/m²K |
| Enthalpy duty | Hot: H_in − H_out; cold: H_out − H_in | 100 → 60 kW hot = 40 kW; wrong direction stays −40 |
| Pump head and coordinate | H = ΔP/(ρg); S = Q√H | 2 bar, 1000 kg/m³: H = 20.39432425955856485 m; 36 m³/h: S = 162.5762720706435071 |
| Standard gas flow | Q·(P/Pref)·(Tref/T)·(Zref/Z) | 100 m³/h at 5 bar, 313.15 K → 430.4296508118775419 Sm³/h; Z = 0.95 → 453.0838429598710968; 1000 kg/h N₂ → 800.1159996649509783 |
| Drying water removal | Feed water − product water | 1000 − 50 = 950 kg/h; 0.3 kg/s − 80 kg/h = 1000 kg/h |

Expected values were written from the governing equations and evaluated separately with 40-digit decimal arithmetic. They are not outputs of the production functions. Test tolerances (relative 1×10⁻¹²) cover binary floating point only; they are not engineering uncertainty.

**Files:** `bridge_method_register.csv` (equation, inputs, applicability, exclusions per method) and `backend/tests/test_bridge_method_references.py` (21 tests, all passing).

**Found while testing:** the converter refuses `t/h` as an ambiguous ton (metric, short or long). That is correct behaviour and is now asserted.

**Not in scope:** whether a costing chart's coordinate means the same physical quantity (for example a chart's own standard-gas basis) is a Phase 3 source-model question, recorded in the register's exclusions.
