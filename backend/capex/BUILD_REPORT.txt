Important findings:
  Garrett whole-plant installation is embedded in the other direct categories.
  Do not add equipment-specific installation or module costs to this method.
  Alternative indirect percentages use the direct subtotal, not final plant cost.
  Offsite/startup factors use core plant cost before those additions.
  Working capital has distinct plant-cost, annual-OPEX and total-investment bases.
  Nottingham rounded table and approximate subtotal formulas are separate modes.
  Lang is an alternative method, never an additional factorial charge.
  Missing Nottingham categories are not given invented Garrett coefficients.

Financial results retain purchased equipment, direct, indirect, core plant,
fixed capital, startup, working capital and total CAPEX separately.
Currency/date/index basis and component scopes must reconcile upstream.

Connector is a pure input adapter and is not attached to the application.
Future LLM interface and draft validator are inactive; no model is invoked.
No frontend, dashboard, deployment or live CAPEX binding added.
